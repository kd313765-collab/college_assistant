SUBJECT: Natural Language Processing (NLP) BCAI052
UNIT 1: Introduction - origins and challenges of NLP, language modeling (grammar based and statistical), regular expressions, finite state automata, English morphology, tokenization, spelling error detection and correction, minimum edit distance; word level analysis - N-grams, smoothing, interpolation and backoff, POS tagging (rule based, stochastic, transformation based), Hidden Markov and maximum entropy models.
UNIT 2: Syntactic analysis - context free grammars, grammar rules for English, treebanks, normal forms, dependency grammar, syntactic parsing, ambiguity, dynamic programming parsing, shallow parsing, probabilistic CFG, probabilistic CYK, feature structures and unification.
UNIT 3: Semantics and pragmatics - representation requirements, first order logic, description logics, syntax driven semantic analysis, word senses, thematic roles, word sense disambiguation, word similarity using thesaurus and distributional methods.
UNIT 4: Basic concepts of speech processing - articulatory phonetics, classification of speech sounds, acoustic phonetics, digital signal processing concepts, short time Fourier transform, filter bank and LPC methods.
UNIT 5: Speech analysis and modeling - feature extraction, speech distortion measures, cepstral distances, LPC, PLP and MFCC coefficients, dynamic time warping; Hidden Markov Models, Viterbi search, Baum-Welch re-estimation.
