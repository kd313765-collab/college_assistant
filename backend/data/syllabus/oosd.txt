SUBJECT: Object Oriented System Design with C++ (OOSD) BCS054
UNIT 1: Introduction - object orientation, object identity, encapsulation, information hiding, polymorphism, importance of modelling, object oriented modelling, introduction to UML, conceptual model of UML, architecture.
UNIT 2: Basic structural modeling - classes, relationships, class and object diagrams; collaboration diagrams, sequence diagrams; behavioural modeling - use cases, activity diagrams, state machine, interaction diagram; architectural modeling - component and deployment diagrams.
UNIT 3: Object oriented analysis and design, object design, design optimization, structured analysis and structured design (SA/SD), Jackson Structured Development, object oriented programming style - reusability, extensibility, robustness, procedural vs OOP, abstraction and encapsulation.
UNIT 4: C++ basics - program structure, namespace, identifiers, variables, constants, enum, operators, typecasting, control structures; C++ functions - call by value and reference, inline functions, macro vs inline, function overloading, default arguments, friend functions, virtual functions.
UNIT 5: Objects and classes - private and public members, static members, constructors and destructors, operator overloading, type conversion; inheritance (single, multiple, multilevel, hierarchical, hybrid), protected members, overriding, virtual base class; polymorphism - pointers, this pointer, virtual and pure virtual functions.
